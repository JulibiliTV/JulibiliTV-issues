# Security reports / 安全问题报告

Please report vulnerabilities privately to [supports@julibilitv.cc](mailto:supports@julibilitv.cc) with the subject `JuliBiliTV security report`.

Include the affected app version, a description of the issue, its potential impact, and steps to reproduce it using test accounts or synthetic data. Do not send real credentials, private media, or information belonging to other users. Keep vulnerability details out of public issues while we investigate.

For ordinary playback or interface problems, use the [bug report form](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=bug_report.yml).

---

发现安全漏洞时，请私下联系 [supports@julibilitv.cc](mailto:supports@julibilitv.cc)，邮件标题可使用 `JuliBiliTV 安全问题`。

请提供受影响的 App 版本、问题描述、可能造成的影响，以及使用测试账号或模拟数据的复现步骤。不要发送真实登录凭据、私有媒体或其他用户的信息。调查期间请勿在公开 Issue 中披露漏洞细节。

普通播放或界面问题，请使用[问题反馈表单](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=bug_report.yml)。
