# JuliBiliTV 用户反馈

[English](README.md)

[官方网站](https://julibilitv.cc) · [联系支持](https://julibilitv.cc/feedback) · [隐私政策](https://julibilitv.cc/privacy)

JuliBiliTV 是一款 Apple TV 媒体播放器。本仓库用于反馈问题、提出功能建议和咨询使用方法。

## 获取帮助

- [反馈问题](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=bug_report.yml)
- [提出功能建议](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=feature_request.yml)
- [咨询使用方法](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=question.yml)
- [搜索已有反馈](https://github.com/JulibiliTV/JulibiliTV-issues/issues?q=is%3Aissue)

支持中文和英文。创建 Issue 需要 GitHub 账号，**不需要在反馈中填写邮箱**，后续沟通直接在 Issue 中进行。

## 如何描述问题

请提供 App 版本、tvOS 版本、Apple TV 型号、复现步骤、实际表现和预期结果。播放问题还可以补充媒体服务器类型及版本、播放引擎（如果知道），以及编码、HDR、音轨或字幕等相关格式信息。

提交前请先搜索已有反馈；如果遇到相同问题，请在原 Issue 中补充信息。反馈和建议有助于改进应用，但不代表已经承诺实现或确定发布日期。

## 公开反馈与私密联系

**Issues 及附件对所有人公开。** 发布截图或日志前，请移除密码、访问令牌、Cookie、API Key、服务器地址、私有媒体链接和个人信息，只保留与问题有关的少量诊断内容。

隐私请求、涉及个人信息的问题，或无法使用 GitHub 时，可联系 [supports@julibilitv.cc](mailto:supports@julibilitv.cc)。请勿发送登录凭据。详情见[支持指引](SUPPORT.md)和[安全问题报告说明](SECURITY.md)。

JuliBiliTV 连接由你选择的媒体服务。本仓库不提供媒体账号、订阅或视频文件。服务器端账号访问、注销和数据删除，请联系服务器管理员或相应服务提供者。
