# JuliBiliTV Support

[简体中文](README.zh-CN.md)

[Official website](https://julibilitv.cc) · [Support](https://julibilitv.cc/feedback) · [Privacy policy](https://julibilitv.cc/privacy)

JuliBiliTV is a media player for Apple TV. This repository is the public place to report problems, suggest improvements, and ask for help.

## Get help

- [Report a bug](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=bug_report.yml)
- [Suggest a feature](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=feature_request.yml)
- [Ask a question](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new?template=question.yml)
- [Search existing issues](https://github.com/JulibiliTV/JulibiliTV-issues/issues?q=is%3Aissue)

You can write in English or Chinese. A GitHub account is needed to open an issue; you do not need to provide an email address in the report. Follow-up happens in the issue thread.

## Make your report useful

Include the app version, tvOS version, Apple TV model, steps to reproduce the problem, and what you expected to happen. For playback issues, include the media server type and version, playback engine if known, and relevant format details such as codec, HDR type, audio, or subtitles.

Search existing issues first. If the same problem is already reported, add your details there. Reports and feature requests help guide development but do not guarantee a release date.

## Public and private support

**Issues and their attachments are public.** Remove passwords, access tokens, cookies, API keys, server addresses, private media links, and personal information before posting screenshots or logs. Share only short, relevant diagnostic excerpts.

For privacy requests, confidential support, or help without a GitHub account, contact [supports@julibilitv.cc](mailto:supports@julibilitv.cc). Do not send login credentials. See the [support guide](SUPPORT.md) and [security reporting instructions](SECURITY.md).

JuliBiliTV connects to media services you choose. This repository does not provide media accounts, subscriptions, or video files. For server-side account access or deletion, contact your server administrator or service provider.
