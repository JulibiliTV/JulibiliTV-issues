# Support / 支持指引

Official website / 官方网站：[julibilitv.cc](https://julibilitv.cc)

Support page / 支持页面：[julibilitv.cc/feedback](https://julibilitv.cc/feedback)

## Bugs, suggestions, and usage questions

[Choose an issue template](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new/choose) for ordinary feedback. English and Chinese are welcome. No email field is required; replies are posted in the issue thread.

For a bug, include:

- App version/build, tvOS version, and Apple TV model. If you cannot find a value, say that it is unknown.
- A short description, numbered reproduction steps, and expected versus actual behavior.
- Media server type/version and player engine, if relevant and known.
- For playback issues, format details and whether one file or multiple files are affected. Do not attach copyrighted media or private download links.
- Optional screenshots or short log excerpts with credentials, server addresses, and personal information removed.

Never post passwords, tokens, cookies, API keys, account identifiers, or private URLs. Check attachments as well as text. If credentials were exposed, revoke or replace them with the service provider; editing an issue alone does not invalidate them.

## Private contact and privacy requests

Contact [supports@julibilitv.cc](mailto:supports@julibilitv.cc) for confidential support, privacy requests, or assistance without GitHub. Include only the information needed to describe your request, without login credentials. For a security vulnerability, follow [SECURITY.md](SECURITY.md).

You can request access, correction, or deletion of information you supplied through our support channels. Account records or media held by your own server or another service must be handled by that provider. Read the [privacy policy](https://julibilitv.cc/privacy) online. In the app, Settings → 隐私政策 displays the URL and a QR code; before sign-in, use Add Data Source → 隐私与支持. Settings → 联系支持 displays the support page and email address.

GitHub hosts public feedback under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Posting here does not require disclosing your email address, but your GitHub username, issue content, and attachments are public.

## 问题、建议与使用咨询

普通反馈请[选择 Issue 模板](https://github.com/JulibiliTV/JulibiliTV-issues/issues/new/choose)，可使用中文或英文。不要求填写邮箱，后续回复会出现在 Issue 中。

反馈问题时请尽量提供：

- App 版本与构建号、tvOS 版本、Apple TV 型号；无法找到的信息可填写“不清楚”。
- 简短的问题描述、分步复现过程、预期结果与实际表现。
- 相关的媒体服务器类型、版本和播放引擎（如果知道）。
- 播放问题涉及的格式，以及是单个文件还是多个文件出现问题；请勿上传受版权保护的媒体或私有下载链接。
- 可选的截图或少量日志片段，先移除凭据、服务器地址及个人信息。

不要公开密码、令牌、Cookie、API Key、账号标识或私有链接，附件也需要检查。如果凭据已泄露，请通过相应服务撤销或更换；仅编辑 Issue 无法让凭据失效。

## 私密联系与隐私请求

涉及个人信息、隐私请求或无法使用 GitHub 时，请联系 [supports@julibilitv.cc](mailto:supports@julibilitv.cc)。仅提供说明问题所需的信息，不要发送登录凭据。安全漏洞请参阅 [SECURITY.md](SECURITY.md)。

你可以申请访问、更正或删除通过我们的支持渠道提供的信息。自己的服务器或其他服务保存的账号、媒体及记录，需要联系对应服务提供者处理。请在线阅读[隐私政策](https://julibilitv.cc/privacy)。应用内“设置 → 隐私政策”显示网址和二维码；未登录时也可通过“添加数据源 → 隐私与支持”查看。“设置 → 联系支持”显示支持页面和邮箱。

公开反馈由 GitHub 托管，并受其[隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)约束。反馈不要求公开邮箱，但 GitHub 用户名、Issue 内容和附件会公开展示。
